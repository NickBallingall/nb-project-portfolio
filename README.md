# Nick Ballingall's Project Portfolio

Please find a selection of projects (mostly as Jupyter Notebooks) that show a sample of my work. This repo mostly exists to support my job applications. The projects are primarily finance-related, but there are some outliers such as an F1 Grand Prix ABM simulation and a song popularity ML project.

## Hero Projects

1. **DMAT (Data Modelling Automation Toolkit)**
	Leverages generative AI to automate key stages of the data modelling pipeline
2. **ML-for-AML**
	Machine learning techniques for anti-money laundering on an anonymised transaction dataset.
3. **spotify-popularity-prediction**
	Using machine learning to predict the popularity of a song on Spotify.
